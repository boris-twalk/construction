# Phase 1 計算公式與適用性

- t → kg：乘 1000；m → mm：乘 1000；degrees → radians：乘 π/180。
- 總懸吊重量 W = 吊物 + 鉤組 + 吊索具 + 其他懸吊附件。UI 簡化為吊物與鉤組／吊具總重量兩欄，必須包含全部附件，避免漏算。
- 完全一致配置下，以精確半徑尋找唯一表格值 Q。不可取鄰近值、內插、從標稱最大吊重推估；空白不是零。禁止工況為 FAIL。
- 可用能力 Qnet = Q − D。D 為依原廠註記明確輸入的扣減值，未輸入不得假設為零；應避免與已納入 W 的重量重複扣減。Phase 1 未自動解讀原廠扣減規則。
- 使用率 U = W / Qnet；U > 1 為 FAIL，U ≤ 1 只代表此算式符合，不代表整體安全或計畫核准。W 全零為資料不足。單項零重量合法、負數、NaN、Infinity 或空值拒絕。
- 最不利工況使用率為各完整工況 U 最大值；存在資料不足則整體資料不足，禁止工況不可能被最大值排序掩蓋。
- 計畫版次或負載表版次改變，既有檢核不可沿用。

查詢需來源、版本、頁碼、核對人與時間、核准旗標及註記確認；虛構資料預設被拒絕，僅 allowFictional 測試模式允許示範。這些旗標目前由 fixture 提供，正式系統必須由後端權限及不可變審查紀錄保證，不能信任瀏覽器提交。

Phase 1 不提供吊索張力、支腿反力或地盤承載公式實作，不自行假設反力、容許壓力或吊點能力。未完成檢核為 INSUFFICIENT_DATA；NOT_APPLICABLE 須有明確適用性依據，不能用來代替缺值。
